# central-conhecimento

Esse projeto é uma base de conhecimento para aplicar e fixar tudo o que tenho estudado ultimamente:
- Git
- GitHub
- Versionamento
- Scrum aplicado ao meu projeto de banco de dados

## Por que este projeto existe

No meu trabalho com sustentação de sistemas, percebi que muitas informações se perdem:
regras de negócio, nomes de tabelas, quem sabe o quê e onde liberar acesso em cada sistema.
Muitas vezes é preciso testar para saber se algo funcionou.

Este projeto nasce para resolver isso: um dicionário de dados que documenta o banco
e guarda, junto de cada procedimento, uma consulta que confirma se deu certo.

## Como estou organizando o trabalho (Scrum)

**Meta da Sprint:** ter o ambiente pronto e a primeira versão do banco do dicionário de dados funcionando.

**Backlog:**
- [x] Instalar MySQL e SSMS
- [ ] Modelo conceitual: entidades e relacionamentos
- [ ] Modelo lógico: colunas e chaves
- [ ] Criar o banco fictício
- [ ] Criar as tabelas a partir da modelagem
- [ ] Inserir dados de exemplo
- [ ] Fazer a primeira consulta no catálogo do banco
- [ ] Escrever a primeira nota do repositório

**Definição de Pronto:** um item só está pronto quando funciona e tem uma nota
explicando o que foi feito, como e por quê.

## O que já aprendi

- **Commit:** guardar uma versão do projeto com uma mensagem explicando a mudança
- **Diff:** comparar a versão antiga com a nova
- **Pull:** trazer para o computador as mudanças que estão no GitHub
- **Push:** enviar para o GitHub as mudanças feitas no computador

## Observação

Todos os dados usados neste projeto são fictícios.
